# 🇮🇳 SchemeSaathi – Government Scheme Finder

**Discover government schemes, scholarships, and support programmes in one place.**

SchemeSaathi is a Python and Streamlit-based web application designed to help users discover government schemes based on their personal profiles and eligibility preferences.

## 🚀 Features

* User registration and login
* Secure password hashing
* Personalized scheme recommendations
* Age-based eligibility filtering
* State and occupation matching
* Income, category, and gender matching
* Keyword-based scheme search
* Scheme descriptions and benefits
* Direct links to official government portals

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* SQLite
* HTML and CSS

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/mohdarsalan25/SchemeSaathi.git
```

### 2. Open the project folder

```bash
cd SchemeSaathi
```

### 3. Install dependencies

```bash
py -m pip install -r requirements.txt
```

### 4. Run the application

```bash
py -m streamlit run app.py
```

### 5. Open in your browser

```text
http://localhost:8501
```

## 🎯 Project Objective

The main objective of SchemeSaathi is to make information about government schemes more accessible by providing a simple platform where users can explore potentially relevant programmes based on their profile.
